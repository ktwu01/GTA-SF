# Historical reference pack

The pack contains 26 distinct archival views: 16 extracted film frames and ten independent photographs or postcards. There are 28 image files, including an alternate-resolution scan and a publication-proof page. The original film, large report PDF and raw TIFF stay outside Git. A 16-second compressed excerpt is included in the public assets. No archival image in this pack was generated by AI.

The source ledger is `data/historical-sf/sources.json`. The public copy is `public/historical-sf/references/manifest.json`. Each image records its source page, original download, date or uncertainty, rights statement, local path and SHA-256. Official LOC metadata snapshots are in `data/historical-sf/snapshots/`.

The historical JPG and PNG assets use ordinary Git blobs through a scoped `.gitattributes` exception. The dedicated experience does not require the original city's Git LFS downloads.

## Verify the committed images

Run the reference checker from the repository root. Python requires Pillow.

```sh
python3 scripts/check_historical_references.py
```

This check verifies image decoding, provenance fields, distinct captures, reference identities and file hashes. It also checks material texture hashes, source IDs and crop bounds against `data/historical-sf/texture-provenance.json`. It does not establish historical fidelity of the rendered scene. Compare that scene with the views in `reference-research.md` and `ferry-detail-research.md`.

## Reproduce the film derivatives

Download the original public-domain film from the Library of Congress.

```sh
mkdir -p data/historical-sf/references
curl -fL https://tile.loc.gov/storage-services/service/mbrs/ntscrm/00015143/00015143.mp4 -o data/historical-sf/references/market-street-1906.mp4
```

Extract the reference frames with the pinned viewing-copy offsets.

```sh
python3 scripts/prepare_historical_references.py
```

Create the silent opening excerpt from seconds 432–448.

```sh
ffmpeg -hide_banner -loglevel error -y -ss 432 -i data/historical-sf/references/market-street-1906.mp4 -t 16 -an -vf 'scale=960:-2' -c:v libx264 -preset fast -crf 24 -movflags +faststart public/historical-sf/market-1906-excerpt.mp4
```

Encoder versions can produce different excerpt bytes. Record a new hash after intentional regeneration. Do not update hashes to hide an unreviewed source change.

The original film is dated April 14, 1906. The original Palace photograph has no recorded capture date. Postcard colors are printed interpretations. Source-backed silhouettes are stronger evidence than inferred dimensions or colors.

## Reproduce the material textures

Run the texture preparation script with Pillow installed.

```sh
python3 scripts/prepare_historical_textures.py
python3 scripts/check_historical_references.py
```

The script uses the bundled historical images. It records crops, tinting, drawn stone courses and derived relief in `data/historical-sf/texture-provenance.json`. These rendering materials are derivatives, not additional archival photographs. The large source PDF and original TIFF are optional research downloads; their URLs and hashes remain in the source ledger.

The visualization was assigned through `collaboration.spawn_agent` with the explicit model argument `gpt-6-astra`. The agent owns the scene geometry, materials, animation, interaction and product UI. The parent gathered public references and performs integration and browser review. Model selection and task ownership are recorded in `data/historical-sf/agent-provenance.json`.
